# JARVIS - AI Voice Assistant

JARVIS is an AI-powered voice assistant developed using Python. It can understand voice commands, answer questions using AI, perform web searches, and control basic computer functions.

## Features

- 🎤 Voice command recognition
- 🤖 AI-powered answers using OpenRouter
- 🌐 Web search for latest information
- 🔊 Voice responses
- 🌐 Open Google and YouTube
- 💻 Open Chrome, Visual Studio, VS Code, Notepad and Calculator
- 📸 Take screenshots
- 🕐 Tell current time and date
- 😂 Tell short jokes
- 🖥️ Simple graphical user interface

## Technologies Used

- Python
- Tkinter
- SpeechRecognition
- OpenRouter API
- OpenAI Python SDK
- PyAutoGUI
- PyAudio
- Python-dotenv

## Project Files

- `gui.py` - Main graphical user interface
- `jarvis.py` - Voice assistant functionality
- `test_gemini.py` - AI/API testing file

## Setup

1. Install Python.
2. Install the required Python packages.
3. Create a `.env` file in the project folder.
4. Add your OpenRouter API key:

`OPENROUTER_API_KEY=your_api_key_here`

5. Run the application:

`python gui.py`

## Security

The `.env` file contains the API key and should not be uploaded to GitHub.

This project was created as a learning project to explore Python, Artificial Intelligence, Voice Recognition, APIs, and GUI development.
